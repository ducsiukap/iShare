Giải phương trình bậc hai

Mình đang ôn chương phương trình bậc hai để chuẩn bị bài kiểm tra giữa kỳ. Cô giao một bài: giải phương trình $x^2 + 2x + 1 = 0$ bằng ít nhất hai cách, rồi so sánh xem cách nào nhanh hơn khi làm trắc nghiệm.

Cách đầu tiên mình làm là dùng công thức nghiệm. Với $a = 1, b = 2, c = 1$ thì biệt thức bằng 0, nên phương trình có nghiệm kép:

$$x = \frac{-b}{2a} = \frac{-2}{2} = -1$$

x=−b2a=−22=−1

Cách thứ hai là nhận ra vế trái chính là hằng đẳng thức $(x + 1)^2$…

Bắt buộc khi từ chối; tác giả thấy lý do này để sửa bài.
