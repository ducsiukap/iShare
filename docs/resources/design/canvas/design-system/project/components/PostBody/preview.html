Giải phương trình bậc hai

Toán họcLớp 10#daiso#phuongtrinh

Mình đang ôn chương phương trình bậc hai. Cô giao một bài: giải phương trình x^2 + 2x + 1 = 0 bằng ít nhất hai cách, rồi so sánh cách nào nhanh hơn khi làm trắc nghiệm, cách nào an toàn hơn khi làm tự luận.

Cách 1: Dùng công thức nghiệm

Với a = 1,\ b = 2,\ c = 1 thì biệt thức \Delta = b^2 - 4ac = 0, nên phương trình có nghiệm kép:

x = \dfrac{-b}{2a} = \dfrac{-2}{2} = -1

Nhận dạng hằng đẳng thức

Vế trái chính là (x + 1)^2, suy ra x = -1 ngay. Cách này luôn dùng được chỉ dùng được khi nhìn ra hằng đẳng thức.

Câu hỏi nhờ mọi người góp ý

  1. Có mẹo nào nhận ra nhanh dạng bình phương của một tổng không?
  2. Nếu hệ số b chẵn, dùng \Delta' = b'^2 - ac có nhanh hơn không?

Phương trình bậc hai có nghiệm kép khi và chỉ khi Δ = 0. — SGK Toán 10

Bạn @minhduc_11 gợi ý dùng code để kiểm tra nghiệm; vòng lặp dùng n //= 10 để bỏ chữ số cuối:

# Đếm số chữ số của số nguyên dương n
def dem_chu_so(n):
    dem = 0
    while n > 0:
        n //= 10
        dem += 1
    return dem

print("Số chữ số:", dem_chu_so(20261125))
