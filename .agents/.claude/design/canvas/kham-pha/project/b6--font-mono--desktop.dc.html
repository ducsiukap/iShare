Bước 6 — Font cho khối code (Q6-01, phần còn mở)

Be Vietnam Pro đã chốt cho giao diện và nội dung (bước 3). Khối code trong bài, bình luận và trình soạn cần một font mono có đủ dấu tiếng Việt cho chú thích và chuỗi. Hai ứng viên, đều giấy phép OFL, có bộ chữ tiếng Việt trên Google Fonts.

A · JetBrains Mono

Chữ cao, rộng, nét đậm hơn; phân biệt rõ I l 1, O 0. Tắt ký tự ghép (=> thành mũi tên) để học sinh thấy đúng toán tử

Trong nội dung bài — theme sáng

Mỗi vòng lặp bỏ đi chữ số cuối bằng phép chia lấy phần nguyên n //= 10, nên số vòng lặp đúng bằng số chữ số của n. Bạn nào dùng len(str(n)) cũng được, nhưng đề yêu cầu không đổi sang xâu.

# Đếm số chữ số của số nguyên dương n (đề ôn Tin học 11)
def dem_chu_so(n):
    dem = 0
    while n > 0:
        n //= 10
        dem += 1
    return dem
​
print("Số chữ số:", dem_chu_so(20261125))  # 8
