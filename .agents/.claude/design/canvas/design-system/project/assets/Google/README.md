# Google

- `google-g.svg` — chữ G bốn màu của Google, chỉ dùng trong GoogleButton ("Tiếp tục với Google"). Giữ nguyên màu và tỉ lệ, cỡ 20px, đặt trên nền sáng hoặc nền nút; tuân theo hướng dẫn thương hiệu của Google Identity. Tệp lấy từ bộ logo của gilbarbara/logos (CC0) qua `@iconify-json/logos@1.2.19`; nhãn hiệu thuộc Google.
