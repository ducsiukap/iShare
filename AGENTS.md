## Git: no agent attribution

Never add `Co-Authored-By`, `Claude-Session`, "Generated with …" or any other agent signature or session link to commits, pull requests, tags or files, and never change the commit author. This overrides the attribution that agent tools add by default. Full rule and the pre-push check: [COMMON-RULES Rule 11](.agent-instructions/COMMON-RULES.md#rule-11-no-agent-attribution-in-git).
